# Content Metrics CLI Contract

The fixture combines source, prose, data, known binary data, Unicode, and every common
line-ending convention.
Generated files use explicit byte buffers so the checkout’s line-ending policy cannot
alter the corpus.

## Content Detection Preserves Name-Based Grouping

Resolved extensions remain on the fast path.
Only unresolved or explicitly ambiguous candidates use shebangs, modelines, required
literals, or named signatures.
Content evidence chooses the analyzer while type rows retain the classification from the
file name, so running analysis cannot change the grouping.
Origin flags are independent of the detected type.

has no metadata-only projection.

measurements as zero.
