The fix (1b3ac793) turns the skip off for the folded tree route. Measure the cost on Linux (default-tree, node-modules-dense and a real tree, paired against the 0.4.0 control) and record it in the ledger as the price of route-equal ages.

Per review C2 on #191, one metadata read per directory and per symlink is the floor report's interface floor for route-equal ages; H185 had taken the tree tier below it. H179 saves no syscall under today's native reader (re-scoped in the registry); what scales with the directory count is H169 phase 3 (open relative to the parent fd). Re-derive the tier's xfloor (make perf-floor) after this cell.
