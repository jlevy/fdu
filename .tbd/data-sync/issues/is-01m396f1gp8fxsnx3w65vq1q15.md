From the #122 review: FDU_BUILD_VERSION is guarded for crates.io via .cargo_vcs_info.json, but a maturin sdist built inside an unrelated git checkout may stamp that checkout's HEAD into --version, and therefore into every installed skill's 'Generated by' line. Verify with the rehearsal sdist built inside a scratch git repo; fix build.rs detection if needed.
