R1 Blocker on PR #96 review (https://github.com/jlevy/fdu/pull/96#issuecomment-5765069350). plan-2026-09-20-directory-query-formats.md:144-151, :199. A directory row's size and age have no defined meaning when its eligible subtree is incomplete (--scan-depth, --allow-partial, --cache only, opened progressive reads). Max-mtime becomes a lower bound, so a directory with recent activity in an unwalked descendant reads as old and matches --modified-before. Fix: state the per-row contract (explicit incompleteness on the typed row and every machine format; size/counts labelled lower bounds; age unknown; whether age predicates may match) and add acceptance cases under fdu-hw5k.
