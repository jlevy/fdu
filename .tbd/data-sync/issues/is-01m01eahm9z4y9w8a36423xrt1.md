Close the topology-coverage gap between the performance plan and the worker experiments. Extend the deterministic corpus system with phase-ordered subjects that expose one-shot sampling errors: fast-prefix/slow-suffix, slow-prefix/fast-suffix, alternating regions, many-small-directories, few-wide-directories, and controlled macOS bulk-fallback cases where portable behavior can be induced safely. Reuse the existing balanced, wide, deep, mixed-metadata, partial, 60k, 120k, 720k, and near-1M regimes rather than inventing a parallel harness.

Acceptance: every recipe has a versioned manifest and independent semantic oracle; generated ordering/topology is deterministic enough to reproduce the intended scheduling phase; scale points straddle calibration and useful-work boundaries; fixtures never contain private paths; partial/permission fixtures are explicitly diagnostic rather than claim-grade; generation, verification, isolation, and cleanup tests pass on supported platforms.
