## Notes

Becomes a three-oracle stack per the reconciliation: the vendored File Rollup conformance packet, recorded-observation replay driven into both engines, and filesystem scenarios over immutable or stepwise-mutated fixtures. Running two live engines against one changing tree is explicitly NOT an oracle -- the observation moments are incomparable and the dual walk perturbs what is being measured. Parity fixtures must separately prove that navigation tallies, literal filters, recent rows, and catalog rows retain the RAW logical extension even where classification uses the canonical suffix.

METABROWSER CONTRACT FOLLOW-UP at 68eeaac (2026-08-24). The acceptance adapter exposes one EngineVersion.semantic_fingerprint. FDU may keep its native type, tag, and reducers fingerprints as separate named components; the thin adapter must combine them using MetaBrowser's canonical sorted-name JSON array plus SHA-256 algorithm. The three-oracle acceptance test must assert that changing any component changes the combined identity and that identical components are stable. Its paged recency slice must also reuse one caller-chosen as_of across the pinned assembly.

Reopened: Reopened at exact PR #47 head 4eac1b2. The new reference embedder cannot reproduce MetaBrowser #74.
