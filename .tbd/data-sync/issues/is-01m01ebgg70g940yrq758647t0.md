Performance evidence built around perf_probe does not prove which fdu a user executes. Add a release-performance smoke that installs the intended development/release artifact through the supported local flow, records its commit/version/hash, enumerates every PATH resolution and relevant shell alias/function, and verifies one authoritative executable before running the natural CLI matrix. It must catch stale cargo binaries, shell aliases such as the former fdumount alias, and a dirty version whose provenance is not recorded.

Acceptance: the smoke fails on multiple or shadowed fdu commands; fresh bash and zsh resolve the same executable; fdu --version and binary hash match the measured build; a real cache-off scan reaches the expected engine; the procedure is safe on a dirty worktree and does not delete unrelated installations without explicit scope; results are included in release qualification rather than kept as session-only notes.
