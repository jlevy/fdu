Request::validate_delivery in crates/fdu-core/src/query/query_request.rs refuses a watch with non-empty content via RequestError::WatchContent, which names --analyze. When the content came from a view, the refusal must name the view: '--view code needs code analysis, which --watch cannot keep current; use a one-shot report' (Python: 'views code needs ...'). Record on the Request (or Query) whether any analyzer was implied, for this message only; it is request provenance, not part of the answer, and is not serialized. --stale-ok with an implied analyzer behaves exactly as with --analyze (compatible sidecar required). Tests in both vocabularies.
