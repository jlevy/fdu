`cargo build --locked -p fdu --no-default-features` fails with 6 errors -- unused imports
(`Provenance`, `open_with_pending_save`) and dead constants (`STYLE_WATCH_RULE`) that are
only used under `cfg(feature = "watch")`, promoted to errors by `-D warnings`.

Verified pre-existing on `claude/control-table-scale-fix` (and therefore the whole #48
line): reverting local changes reproduces the same 6 errors.

crates/fdu/Cargo.toml documents the contract this breaks: "Without it the command line
still builds and works, just without `--watch`, which is what keeps the watch layer
deletable." The layer is not deletable today.

No gate exercises this shape. `make check`'s `lib-only` target builds `fdu-core` under
`--no-default-features` (all four feature combinations) but never the `fdu` binary, so
the claim in the manifest is tested nowhere.

Fix: gate the watch-only imports and constants with `cfg(feature = "watch")`, and add the
featureless CLI build to `lib-only` (a check, not a full build, is enough to keep it
cheap).
