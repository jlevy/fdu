Found by the pdu track's profiling (research-2026-09-29-uniformly-faster-than-pdu.md): fdu --format json without --view emits the complete List view, 50 MB and 0.88 s on node-modules-dense, while --view tree --format json is 28 KB and 0.080 s. 74% of that run's 6.7G instructions are the String-cloning sort H186 targets. Decide whether JSON's default view is intended to differ from text's default tree (a machine consumer may want every entry), and document it either way; if unintended, changing it is an output change that needs a golden and the output design guide.
