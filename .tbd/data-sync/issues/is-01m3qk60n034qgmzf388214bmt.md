Decided 2026-09-30 (maintainer accepted the recommendation): the output itself is by design. docs/project/architecture/fdu-surface-architecture.md (List Selection and Presentation): 'The metadata default view is List, whose automatic human format is the existing bounded directory tree ... machine List requests materialize matching rows.' So fdu --format json with no --view emits every matching row for machine consumers, and that stays. What remains is speed: on node-modules-dense it is 50 MB in 0.88 s, of which the pdu track's profile (research-2026-09-29-uniformly-faster-than-pdu.md) attributes about 3.4G instructions to a stable sort and 1.67G + 1.4G + 0.9G to write_json_string, BufWriter and lossy UTF-8 decoding. H186's borrowed-name comparator cut it only 6.18G to 5.76G. Profile and speed up this machine path without changing its bytes.
