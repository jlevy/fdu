Current evidence: crates/fdu/src/watch.rs apply_reverified retries three optimistic clock checks, then acquires IndexHandle write access and calls reverify_observation while holding the writer lock. Reverification performs one symlink_metadata call per queued operation. A slow, blocked, or reentrant filesystem can therefore stall every reader and writer for an unbounded interval; a large observation amplifies the lock hold. Replace the fallback with a crate-private linearizable apply-if-clock operation: capture root and clock, reverify entirely outside the lock, then acquire the writer only to accept the verified batch if the clock still matches. Keep a small retry budget. On exhaustion, do not stat under the lock or spin indefinitely; atomically publish a conservative root invalidation with an explicit contention reason, release the lock, and let the normal reconciliation loop converge. Add deterministic conflict injection proving: I/O occurs lock-free, readers and an unrelated writer make progress during a blocked verifier, successful commits are clock-current, exhausted contention leaves the index non-fresh until reconciliation, callbacks run after unlock, and verifier errors preserve coherent retry state. Tests use barriers/channels and bounded deadlines, not sleeps. Preserve the Delta-only mutation contract and return typed errors rather than poisoning or panicking.

## Notes

Implemented 2026-08-09. Watch arbitration now captures root/scope/clock through focused IndexHandle operations, performs every verification outside locks, and commits only through a crate-private apply_if_clock linearization point. Three bounded conflicts produce an explicit root WatchContention delta and stale freshness; normal pending reconciliation restores freshness. There is no stat-under-writer fallback. Deterministic channel/deadline tests block the verifier while a reader and unrelated writer both progress, force a clock conflict then prove current-clock commit, exhaust every retry and prove stale-until-reconciled behavior, verify one call on the stable path, and prove verifier errors mutate no clock, totals, freshness, or retry state. Existing reentrant sink tests prove callbacks run after unlock. Watch-only and all-feature suites pass with pedantic Clippy.
